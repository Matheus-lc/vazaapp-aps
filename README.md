# VazaApp — Análise e Projeto de Software

Versão refatorada da documentação acadêmica: **35 casos de uso**, **24 regras de negócio**, **35 requisitos funcionais**, **8 requisitos não funcionais** e diagramas em **Mermaid**.

O VazaApp oferece sugestões de desculpas personalizadas a partir da situação, categoria, destinatário, proximidade e contexto informado. A geração seleciona e personaliza modelos de um catálogo. O escopo ampliado inclui conta, perfil, destinatários, pedidos, histórico, favoritos, avaliações e administração do catálogo.
